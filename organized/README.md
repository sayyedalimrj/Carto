# پوشه‌ی organized — چیدمان مرتب‌شده‌ی افزونه‌ها

این پوشه یک **نمای مرتب و دسته‌بندی‌شده** از همه‌ی افزونه‌های پروژه‌ی Carto است.
هدف آن این است که یک کاربر تازه‌کار بتواند به‌سادگی فایل درست را برای سکوی مورد نظر
خود (ArcMap یا ArcGIS Pro) پیدا کند.

> 🔸 **نکته‌ی مهم:** فایل‌های اصلی `.pyt` همچنان در **ریشه‌ی مخزن** باقی مانده‌اند و
> دست‌نخورده هستند. فایل‌های داخل این پوشه **کپی** آن‌ها هستند. دلیل این کار آن است که
> دو ابزار «Master» (یعنی `Master_ArcMap_Carto.pyt` و `Master_Pro_Carto.pyt`) فایل‌های
> افزونه‌ها را از کنار خودشان (ریشه‌ی مخزن) بارگذاری می‌کنند و جابه‌جا کردن فایل‌ها آن‌ها را
> از کار می‌اندازد.

## ساختار

```
organized/
  Plugin01/   (پل و آبگذر — Bridge & Culvert)
    ArcMap/   نسخه‌ی ArcMap (پایتون ۲٫۷)
    Pro/      نسخه‌ی ArcGIS Pro (پایتون ۳)
    Legacy/   نسخه‌های قدیمی/مرجع (در صورت وجود)
  Plugin02/   (جداسازی عوارض از جاده — Road Deconflict)
    ArcMap/  Pro/  Legacy/
  Plugin03/   (بهینه‌ساز برچسب منحنی میزان — Contour Label Optimizer)
    ArcMap/  Pro/  Legacy/
  Plugin04/   (جداسازی متن ارتفاع — Elevation Text Deconflict)
    ArcMap/  Pro/  Legacy/
  Plugin05/   (پاک‌سازی امن منحنی میزان — Safe Contour Cleaner)
    ArcMap/  Pro/  Legacy/
  Plugin06/   (چرخش نماد چشمه — Spring Rotation)
    ArcMap/  Pro/  Legacy/
  Plugin07/   (سازنده‌ی دسته‌ای شبکه — Batch Grid Builder)
    ArcMap/  Pro/  Legacy/
  Master/     (جعبه‌ابزارهای یکپارچه که همه‌ی افزونه‌ها را کنار هم نشان می‌دهند)
    ArcMap/  Pro/
```

## معنی هر پوشه

- **ArcMap/** — نسخه‌ی سازگار با ArcMap نسخه‌ی ۱۰ (پایتون ۲٫۷). برای کاربرانی که هنوز
  از ArcMap استفاده می‌کنند.
- **Pro/** — نسخه‌ی بومی ArcGIS Pro (پایتون ۳). برای کاربرانی که به Pro مهاجرت کرده‌اند.
- **Legacy/** — نسخه‌های قدیمی که فقط برای **مرجع** نگه داشته می‌شوند و برای کار جدید
  توصیه **نمی‌شوند**. اگر این پوشه خالی بود یا فقط فایل یادداشت داشت، یعنی نسخه‌ی قدیمی
  در این نسخه از مخزن موجود نیست.
