# افزونه ۰۳ — بهینه‌ساز برچسب منحنی میزان (Contour Label Optimizer)

> راهنمای کامل و گام‌به‌گام برای کاربر تازه‌کار. اگر هنوز راهنمای کلی را نخوانده‌اید،
> ابتدا [راهنمای کلی Carto](../overview/00_Carto_Overview_FA.md) را ببینید.

---

## ۱) این افزونه چه می‌کند؟

این افزونه برای **منحنی‌های میزان (Contour lines)** بهترین نقطه را برای گذاشتن **برچسب
عدد ارتفاع** پیدا می‌کند. در هر بازه‌ی مشخص از طول خط، یک نقطه‌ی «لنگر برچسب» انتخاب
می‌شود که:

- روی بخشی از منحنی باشد که **کمترین خمیدگی (پیچ‌وتاب)** را دارد (برچسب روی خط صاف خواناتر است)،
- با **موانع** (عوارض دیگر و برچسب‌های موجود) **برخورد نکند**،
- ترجیحاً **نزدیک مرکز بازه** باشد.

به زبان ساده: «روی هر منحنی، هر چند صد متر یک‌بار، تمیزترین جای ممکن را برای نوشتن عدد
ارتفاع انتخاب کن.»

| ابزار | کار |
|------|-----|

## ۴) پیش‌نیازها و محیط

- ArcMap ۱۰ یا ArcGIS Pro.
- لایه‌ی **منحنی میزان (Polyline)** با یک **فیلد عددی ارتفاع**.
- داده باید در **سیستم مختصات تصویرشده (واحد طولی، مثل متر)** باشد؛ ورودی جغرافیایی
  (درجه) پذیرفته نمی‌شود چون محاسبه‌ها بر حسب واحد طولی است.
- یک **جئودیتابیس فایلی** برای خروجی.
- (اختیاری) لایه‌های مانع و لایه‌ی Annotation موجود.

## ۶) پارامترها به زبان ساده (ابزار اصلی)

این ابزار پارامترهای زیادی دارد که در دسته‌ها گروه‌بندی شده‌اند. برای شروع، فقط
پارامترهای الزامی را تنظیم کنید و بقیه را روی پیش‌فرض بگذارید.

### ورودی پایه
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Contour lines | لایه‌ی منحنی میزان. | — (الزامی) |
| Elevation field | فیلد عددی ارتفاع (متن برچسب از این فیلد می‌آید). | — (الزامی) |
| Selection mode | `ALL` همه‌ی منحنی‌ها، یا `MAJOR_INTERVAL` فقط منحنی‌های اصلی. | `ALL` |
| Major interval | فاصله‌ی منحنی‌های اصلی (مثلاً ۱۰۰ یعنی ارتفاع‌های مضرب ۱۰۰). | `100.0` |
| Along-line interval (meters) | فاصله‌ی بین برچسب‌ها در امتداد خط (هر چند متر یک برچسب). | `500.0` |
| Safe distance from obstacles (mm on map) | فاصله‌ی ایمن برچسب از موانع، بر حسب میلی‌متر روی نقشه. | `2.0` |
| Extra halo/mask margin (mm) | حاشیه‌ی اضافی دور برچسب. | `0.0` |
| Map scale denominator | مخرج مقیاس نقشه (مثلاً ۲۵۰۰۰ برای ۱:۲۵۰۰۰). برای تبدیل میلی‌متر به واحد نقشه لازم است. | `25000.0` |

### موانع (Obstacles)
| پارامتر | معنی |
|------|------|
| Obstacle layers | لایه‌های مانع (خط/پلیگون/نقطه) که برچسب نباید رویشان بیفتد (اختیاری، چندتایی). |
| Existing annotation layer | لایه‌ی Annotation موجود به‌عنوان مانع و منبع تخمین اندازه‌ی متن (اختیاری). |

### اندازه‌ی متن (Text Metrics)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Derive text metrics from annotation | اگر Annotation دادید، اندازه‌ی متن از آن استخراج شود. | روشن |
| Font size (points) | اندازه‌ی قلم اگر از Annotation استخراج نشد. | `8.0` |
| Average character width factor | ضریب میانگین عرض کاراکتر. | `0.6` |

### خمیدگی (Curvature)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Curvature method | روش سنجش خمیدگی: `Hybrid`/`ChordRatio`/`MaxDeflection`/`CurvatureEnergy`. | `Hybrid` |
| Curvature sampling step (meters) | فاصله‌ی نمونه‌گیری برای محاسبه‌ی خمیدگی. | `5.0` |
| Hybrid weights (chord ratio / max deflection / curvature energy) | وزن هر مؤلفه در روش Hybrid. | `0.5` / `0.3` / `0.2` |

### امتیازدهی و آستانه‌ها (Scoring / Thresholds)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Weight: curvature | وزن خمیدگی در امتیاز نهایی. | `1.0` |
| Weight: overlap area | وزن مساحت هم‌پوشانی با موانع. | `5.0` |
| Weight: window-center preference | وزن تمایل به مرکز بازه. | `0.25` |
| Max allowed overlap area | حداکثر هم‌پوشانی مجاز (اختیاری). | — |
| Max allowed curvature score | حداکثر امتیاز خمیدگی مجاز (اختیاری). | — |
| Minimum contour part length (meters) | حداقل طول قطعه‌ی منحنی برای برچسب. | `0.0` |
| Short part policy | برای قطعه‌های کوتاه: `PLACE_CENTER` (برچسب در مرکز) یا `SKIP` (رد شدن). | `PLACE_CENTER` |

### خروجی‌ها (Outputs)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Output workspace | محل ذخیره (`.gdb` توصیه‌شده). | — (الزامی) |
| Output segments name | نام لایه‌ی قطعات منحنی خروجی. | `ContourLabelSegments` |
| Output points name | نام لایه‌ی نقاط لنگر برچسب. | `ContourLabelPoints` |
| Create QA footprints | ساخت پلیگون‌های محدوده‌ی برچسب برای QA. | خاموش |
| QA footprints name | نام لایه‌ی footprintها (اگر فعال باشد). | `ContourLabelFootprints` |
| Create statistics table | ساخت جدول آماری. | روشن |
| Statistics table name | نام جدول آمار. | `ContourLabelStats` |

### پیشرفته (Advanced)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Internal tries per window | تعداد تلاش داخلی برای بهبود موقعیت در هر بازه. | `11` |
| Use legacy obstacle evaluation | استفاده از روش قدیمی ارزیابی موانع (کندتر؛ فقط برای آزمون/سازگاری). روش پیش‌فرض جدید با NumPy سریع‌تر است. | خاموش |

> خروجی‌های مشتق (Derived) مثل مسیر لایه‌ها و فایل لاگ به‌صورت خودکار پر می‌شوند.

## ۸) راهنمای گام‌به‌گام استفاده

1. لایه‌ی **منحنی میزان** را به نقشه اضافه کنید؛ مطمئن شوید سیستم مختصات **تصویرشده** دارد.
2. ابزار **Optimize Contour Label Anchors** را باز کنید.
3. لایه‌ی منحنی را در **Contour lines** و فیلد ارتفاع را در **Elevation field** بگذارید.
4. **Along-line interval** را بر اساس این‌که هر چند متر یک برچسب می‌خواهید تنظیم کنید (مثلاً ۵۰۰).
5. **Map scale denominator** را برابر مقیاس نقشه‌تان بگذارید (مثلاً ۲۵۰۰۰).
6. اگر عوارض یا برچسب‌های موجود دارید که نباید روی آن‌ها بیفتد، آن‌ها را در
   **Obstacle layers** و **Existing annotation** بگذارید.
7. یک **Output workspace** انتخاب کنید.
8. روی **Run** بزنید.
9. لایه‌ی نقاط لنگر و قطعات خروجی ساخته می‌شوند. سپس می‌توانید با ابزار **Validate** کیفیت
   هم‌پوشانی‌ها را بررسی کنید.

---

## ۹) داده‌ی ورودی موردانتظار

- **منحنی میزان:** لایه‌ی خطی با فیلد عددی ارتفاع، در سیستم مختصات تصویرشده.
- **موانع (اختیاری):** هر لایه‌ای که برچسب نباید رویش بیفتد.
- **Annotation موجود (اختیاری):** برای تخمین اندازه‌ی واقعی متن.

---

## ۱۰) خروجی چه شکلی است؟

- **نقاط لنگر برچسب** (نقطه‌ای): جایی که هر برچسب باید قرار گیرد.
- **قطعات منحنی** (خطی): بازه‌هایی که هر برچسب به آن‌ها تعلق دارد.
- (اختیاری) **footprintهای QA** (پلیگونی) و **جدول آماری**.
- جدول گزارش **QA** از ابزار Validate.

---

## ۱۱) اشتباهات رایج و رفع آن‌ها

| مشکل | علت احتمالی | راه‌حل |
|------|------|--------|
| خطای «ورودی باید تصویرشده باشد» | داده در سیستم جغرافیایی (درجه) است | داده را به سیستم تصویرشده با واحد متر ببرید (Project). |
| برچسب‌های خیلی کم | فاصله‌ی بازه (interval) خیلی بزرگ یا سیاست قطعه‌ی کوتاه روی SKIP | **Along-line interval** را کم کنید یا **Short part policy** را روی `PLACE_CENTER` بگذارید. |
| برچسب‌ها روی موانع افتاده‌اند | لایه‌های مانع وارد نشده یا فاصله‌ی ایمن کم است | موانع را اضافه کنید و **Safe distance** را افزایش دهید. |
| اجرا کند است | داده‌ی بزرگ با روش قدیمی ارزیابی | **Use legacy obstacle evaluation** را خاموش بگذارید تا روش سریع NumPy استفاده شود. |

## ۱۲) نکات و بهترین روش‌ها

- مقدار **Map scale denominator** باید با مقیاس واقعی چاپ نقشه بخواند؛ وگرنه تبدیل
  میلی‌متر به واحد نقشه اشتباه می‌شود.
- روش پیش‌فرض ارزیابی موانع (NumPy) برای داده‌ی بزرگ بسیار سریع‌تر است؛ آن را روشن (یعنی
  legacy را خاموش) نگه دارید.
- ابتدا روی یک بخش کوچک از منحنی‌ها آزمایش کنید تا وزن‌ها و آستانه‌ها را تنظیم کنید.
