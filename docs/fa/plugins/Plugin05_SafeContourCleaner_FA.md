# افزونه ۰۵ — پاک‌سازی امن منحنی میزان (Safe Contour Cleaner)

> راهنمای کامل و گام‌به‌گام برای کاربر تازه‌کار. اگر هنوز راهنمای کلی را نخوانده‌اید،
> ابتدا [راهنمای کلی Carto](../overview/00_Carto_Overview_FA.md) را ببینید.

---

## ۱) این افزونه چه می‌کند؟

در نواحی پرشیب، منحنی‌های میزان خیلی به هم نزدیک و متراکم می‌شوند و چاپ نقشه را شلوغ
می‌کنند. این افزونه در یک **ناحیه‌ی مشخص (AOI)** منحنی‌های **متراکم** را شناسایی و
**به‌صورت ایمن** حذف می‌کند تا نقشه برای چاپ تمیز شود — بدون اینکه فایل اصلی شما تغییر کند.

«ایمن» یعنی:
- خروجی روی **کپی** ساخته می‌شود؛ داده‌ی اصلی دست‌نخورده می‌ماند.
- منحنی‌های **محافظت‌شده** (مثلاً منحنی‌های اصلی/شاخص) هرگز حذف نمی‌شوند.
- پاک‌سازی فقط در محدوده‌ی تعیین‌شده انجام می‌شود و به‌صورت پیش‌فرض اجازه‌ی پاک‌سازی کل
  داده داده نمی‌شود (تا از اشتباه جلوگیری شود).

---

## ۲) نسخه‌ها: کدام برای ArcMap، کدام برای Pro

| سکو | فایل |
|------|------|
| **ArcMap** (پایتون ۲٫۷) | `Plugin05_SafeContourCleaner_ArcMap_v5_hardened.pyt` |
| **ArcGIS Pro** (پایتون ۳) | `Plugin05_SafeContourCleaner_Pro_v5_native.pyt` |

نسخه‌ی مرتب‌شده: `organized/Plugin05/ArcMap/` و `organized/Plugin05/Pro/`.

---

## ۳) ابزارهای داخل این افزونه

| ابزار | کار |
|------|-----|
| AOI Brush Builder (Create / Add / Subtract) | ساخت یک پلیگون ناحیه (AOI) از «قلم‌ضربه‌ها» (خط/پلیگون). به شما کمک می‌کند محدوده‌ی پاک‌سازی را به‌سادگی ترسیم کنید. |
| Safe Contour Cleaner (Print-Ready) | ابزار اصلی: پاک‌سازی منحنی‌های متراکم در ناحیه‌ی مشخص. |

> یک گردش‌کار رایج: اول با **AOI Brush Builder** محدوده را بسازید، بعد آن را به
> **Safe Contour Cleaner** بدهید.

---

## ۴) پیش‌نیازها و محیط

- ArcMap ۱۰ یا ArcGIS Pro.
- یک **جئودیتابیس فایلی** برای خروجی.
- لایه‌ی **منحنی میزان (Polyline)**.
- (توصیه‌شده) یک **قاب/نیت‌لاین (Frame/Neatline)** پلیگونی برای محدودکردن ناحیه‌ی کار.
- داده در سیستم مختصات تصویرشده با واحد متر توصیه می‌شود.

### ابزار ۲: Safe Contour Cleaner

پارامترها در ۹ دسته گروه‌بندی شده‌اند. مهم‌ترین‌ها را اینجا می‌بینید:

**۱) ورودی‌ها**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Input Contour Layers | لایه(های) منحلی میزان ورودی (چندتایی). | — (الزامی) |
| Frame / Neatline Polygon | پلیگون قاب (به‌شدت توصیه‌شده). | — |

**۲) ایمنی (Safety)**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Safe Margin INSIDE Frame (map units) | حاشیه‌ی ایمن داخل قاب (واحد نقشه). | `0.0` |
| Safe Margin INSIDE Frame (mm on map) | همان حاشیه بر حسب میلی‌متر. | `0.0` |

**۳) تشخیص ناحیه‌ی متراکم**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Dense Threshold Distance | فاصله‌ای که زیر آن، منحنی‌ها «متراکم» شمرده می‌شوند. | `20.0` |
| Minimum Neighbors for Dense | حداقل تعداد همسایه برای متراکم‌شمردن (≥۱). | `1` |

**۴) ناحیه‌ی هدف (AOI)**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| AOI Mode | کجا پاک‌سازی شود: فقط قاب / فقط AOI سفارشی / قاب و AOI / کل داده. | «Frame only» |
| Custom AOI Polygon | پلیگون AOI سفارشی (خروجی ابزار Brush Builder). | — |

**۵) ساخت ماسک حذف**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Mask Mode | ماسک خودکار از نواحی متراکم / استفاده از AOI به‌عنوان ماسک / ماسک خارجی. | «Auto mask…» |
| External Mask Polygon | پلیگون ماسک خارجی (اختیاری). | — |

**۶) قواعد (Rules)**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Eligible Contours SQL | شرط SQL برای منحنی‌هایی که **مجاز** به پاک‌شدن‌اند. | `1=1` |
| Protected Contours SQL | شرط SQL برای منحنی‌هایی که **هرگز** نباید پاک شوند (مثلاً منحنی‌های اصلی). | خالی |

**۷) راهبرد پاک‌سازی**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Removal Method | روش حذف: «Segment Erase» (حذف فقط بخش متراکم خط، توصیه‌شده) یا «Delete Whole Features» (حذف کل عارضه). | «Segment Erase» |
| Min segment length to delete after erase | حداقل طول قطعه‌ی باقی‌مانده که حذف شود. | `0.0` |

**۸) خروجی‌ها**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Output Workspace | محل ذخیره. | — |
| Output Clean Contours Name | نام لایه‌ی منحنی‌های تمیزشده. | `Contours_CartoClean` |
| Create Removed Segments Layer | ساخت لایه‌ی قطعات حذف‌شده. | روشن |
| Create Review Layer (dense but protected) | لایه‌ی بازبینی: متراکم ولی محافظت‌شده. | روشن |
| Create Mask Output Layer | ساخت لایه‌ی ماسک. | روشن |
| Write CSV Report | نوشتن گزارش CSV. | روشن |
| Add outputs to current map | افزودن خروجی‌ها به نقشه. | روشن |
| Dry Run / Preview Mode | فقط پیش‌نمایش؛ هیچ خروجی تمیزشده‌ای ساخته نمی‌شود. | خاموش |
| Near Chunk Size | اندازه‌ی دسته در محاسبه‌ی NEAR (مدیریت حافظه روی داده‌ی بزرگ). | `50000` |

**۹) بازنویسی‌های ایمنی**
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Allow Full-Map Processing if AOI is Empty | اگر خاموش (پیش‌فرض): AOI خالی خطا می‌دهد. اگر روشن: کل نقشه پردازش می‌شود (با هشدار). | خاموش |

## ۷) راهنمای گام‌به‌گام استفاده

1. (اختیاری ولی توصیه‌شده) با ابزار **AOI Brush Builder** محدوده‌ی پاک‌سازی را بسازید:
   یک لایه‌ی خط/پلیگون «قلم» بکشید، شعاع را تنظیم کنید و خروجی AOI بگیرید.
2. ابزار **Safe Contour Cleaner** را باز کنید.
3. لایه‌ی منحنی میزان را در **Input Contour Layers** بگذارید.
4. یک **Frame / Neatline** بدهید و **AOI Mode** را انتخاب کنید (مثلاً «Frame only» یا
   «Custom AOI only» اگر AOI ساختید).
5. **Dense Threshold Distance** را تنظیم کنید (فاصله‌ای که زیر آن متراکم محسوب شود).
6. در بخش **Rules**، اگر منحنی‌های اصلی دارید که نباید پاک شوند، شرط آن‌ها را در
   **Protected Contours SQL** بنویسید.
7. **Removal Method** را روی «Segment Erase» بگذارید (فقط بخش متراکم خط حذف می‌شود).
8. ابتدا **Dry Run** را روشن کنید و یک‌بار اجرا کنید تا ببینید چه چیزی حذف می‌شود.
9. اگر نتیجه درست بود، **Dry Run** را خاموش و دوباره **Run** کنید.
10. خروجی تمیزشده و لایه‌های کمکی (حذف‌شده‌ها، بازبینی، ماسک) ساخته می‌شوند.

---

## ۸) داده‌ی ورودی موردانتظار

- **منحنی میزان:** یک یا چند لایه‌ی خطی.
- **قاب (اختیاری ولی توصیه‌شده):** پلیگون نیت‌لاین.
- **AOI سفارشی (اختیاری):** پلیگون محدوده (می‌تواند خروجی Brush Builder باشد).

---

## ۹) خروجی چه شکلی است؟

- **لایه‌ی منحنی‌های تمیزشده** (`Contours_CartoClean`).
- (اختیاری) **قطعات حذف‌شده**، **لایه‌ی بازبینی** (متراکم ولی محافظت‌شده)، **لایه‌ی ماسک** و **گزارش CSV**.
- داده‌ی اصلی شما تغییر نمی‌کند.

---

## ۱۰) اشتباهات رایج و رفع آن‌ها

| مشکل | علت احتمالی | راه‌حل |
|------|------|--------|
| خطای «AOI خالی است» | قاب/AOI مشخص نشده و اجازه‌ی پردازش کل داده خاموش است | یک Frame یا AOI بدهید؛ یا (با احتیاط) **Allow Full-Map Processing** را روشن کنید. |
| منحنی‌های مهم هم حذف شدند | شرط محافظت تنظیم نشده | منحنی‌های اصلی را در **Protected Contours SQL** محافظت کنید. |
| چیزی حذف نشد | آستانه‌ی تراکم خیلی کوچک یا حداقل همسایه زیاد | **Dense Threshold Distance** را بزرگ‌تر و **Minimum Neighbors** را کوچک‌تر کنید. |
| اجرا روی داده‌ی بزرگ کند است | اندازه‌ی دسته‌ی NEAR نامناسب | **Near Chunk Size** را تنظیم کنید. |
| نگران تغییر داده‌ی اصلی هستم | — | خروجی همیشه روی کپی است؛ برای اطمینان ابتدا **Dry Run** را اجرا کنید. |

## ۱۱) نکات و بهترین روش‌ها

- **همیشه اول Dry Run بزنید** تا قبل از حذف واقعی، نتیجه را ببینید.
- منحنی‌های شاخص/اصلی را با **Protected Contours SQL** محافظت کنید.
- «Segment Erase» معمولاً بهتر از حذف کل عارضه است، چون فقط بخش متراکم را برمی‌دارد و
  پیوستگی بصری منحنی حفظ می‌شود.
- برای ترسیم سریع محدوده، از ابزار **AOI Brush Builder** استفاده کنید.

---

## ۱۲) تفاوت‌های نسخه‌ی ArcMap و Pro

- رفتار، پارامترها و خروجی یکسان است.
- تبدیل «میلی‌متر روی نقشه» به واحد نقشه به **مقیاس قاب‌نقشه (DataFrame/Map)** فعلی نیاز
  دارد؛ در ArcMap از DataFrame و در Pro از Map فعال خوانده می‌شود.
- نسخه‌ی Pro فقط از `arcpy.mp` استفاده می‌کند.
