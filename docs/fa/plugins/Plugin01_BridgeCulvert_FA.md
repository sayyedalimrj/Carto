# افزونه ۰۱ — پل و آبگذر (Bridge & Culvert Toolkit)

> راهنمای کامل و گام‌به‌گام برای کاربر تازه‌کار. اگر هنوز راهنمای کلی را نخوانده‌اید،
> ابتدا [راهنمای کلی Carto](../overview/00_Carto_Overview_FA.md) را ببینید.

---

## ۱) این افزونه چه می‌کند؟

این افزونه برای **محل تقاطع جاده با آبراهه (رودخانه/کانال)** نماد **پل** یا **آبگذر**
می‌سازد و **جهت (زاویه‌ی چرخش)** آن نماد را درست تنظیم می‌کند تا نماد به‌درستی روی خط
بنشیند.

به زبان ساده:
- در محلی که جاده از روی رودخانه رد می‌شود، یک نقطه‌ی **پل** می‌گذارد و آن را
  هم‌راستا با **جاده** می‌چرخاند.
- در محلی که جاده از روی کانال/آبراهه عبور می‌کند، یک نقطه‌ی **آبگذر** می‌گذارد و آن را
  هم‌راستا با **آبراهه** می‌چرخاند.
- یک فیلتر هوشمند، تقاطع‌های «واقعی» را از تماس‌های انتهایی و سه‌راهی‌های الکی
  (T-junction) جدا می‌کند تا نماد در جای اشتباه ساخته نشود.

علاوه بر ساخت نقطه، دو ابزار دیگر هم دارد که **زاویه‌ی نقاط موجود** را به‌روزرسانی می‌کنند
بدون اینکه مکان نقطه را جابه‌جا کنند.

---

## ۲) نسخه‌ها: کدام برای ArcMap، کدام برای Pro

| سکو (نرم‌افزار) | فایل |
|------|------|
| **ArcMap** (پایتون ۲٫۷) | `Plugin01_BridgeCulvert_ArcMap_py27.pyt` |
| **ArcGIS Pro** (پایتون ۳) | `Plugin01_BridgeCulvert_Pro_py3.pyt` |

هر دو نسخه ابزارها، پارامترها و خروجی یکسانی دارند. فقط نسخه‌ی مناسب نرم‌افزار خود را انتخاب کنید.

- نسخه‌ی مرتب‌شده در: `organized/Plugin01/ArcMap/` و `organized/Plugin01/Pro/`

---

## ۳) ابزارهای داخل این افزونه

این جعبه‌ابزار **چهار ابزار** دارد:

| شماره | نام ابزار | کار |
|:----:|-----------|-----|
| ۰۱ | Create Bridge Points (Road × Drain) | ساخت نقاط پل در تقاطع‌های واقعی جاده×آبراهه؛ چرخش هم‌راستا با **جاده** |
| ۰۲ | Create Culvert Points (Road × Drain) | ساخت نقاط آبگذر در تقاطع‌های واقعی؛ چرخش هم‌راستا با **آبراهه** |
| ۰۳ | Rotate Existing Bridge Points (from Roads) | به‌روزرسانی زاویه‌ی نقاط پل موجود از نزدیک‌ترین **جاده**؛ مکان جابه‌جا نمی‌شود |
| ۰۴ | Rotate Existing Culvert Points (from Drainage) | به‌روزرسانی زاویه‌ی نقاط آبگذر موجود از نزدیک‌ترین **آبراهه**؛ مکان جابه‌جا نمی‌شود |

> ابزارهای ۰۳ و ۰۴ **هرگز مکان نقطه را جابه‌جا نمی‌کنند**؛ فقط فیلدهای زاویه را به‌روز می‌کنند.

---

## ۴) پیش‌نیازها و محیط

- ArcMap نسخه‌ی ۱۰ (برای نسخه‌ی ArcMap) یا ArcGIS Pro (برای نسخه‌ی Pro).
- یک **جئودیتابیس فایلی (`.gdb`)** یا یک **پوشه** برای ذخیره‌ی خروجی.
- لایه‌های ورودی **خط (Polyline)** برای جاده‌ها و آبراهه‌ها.
- بهتر است داده‌ها در یک **سیستم مختصات تصویرشده با واحد متر** باشند، چون «فاصله‌ی
  نمونه‌گیری» و «تلورانس انتهایی» بر حسب **واحد نقشه** سنجیده می‌شوند.

---

## ۵) نحوه‌ی بارگذاری جعبه‌ابزار

### در ArcMap
1. پنجره‌ی **ArcToolbox** را باز کنید.
2. در فضای خالی آن **راست‌کلیک** کرده و **Add Toolbox…** را بزنید.
3. فایل `Plugin01_BridgeCulvert_ArcMap_py27.pyt` را پیدا و انتخاب کنید.
4. جعبه‌ابزار با چهار ابزارش ظاهر می‌شود. روی ابزار موردنظر دوبار کلیک کنید.

### در ArcGIS Pro
1. پنجره‌ی **Catalog** را باز کنید.
2. روی **Toolboxes** راست‌کلیک کرده و **Add Toolbox** را بزنید.
3. فایل `Plugin01_BridgeCulvert_Pro_py3.pyt` را انتخاب کنید.
4. جعبه‌ابزار را باز کنید و روی ابزار موردنظر دوبار کلیک کنید.

> 💡 می‌توانید به‌جای این فایل، جعبه‌ابزار یکپارچه (`Master_ArcMap_Carto.pyt` یا
> `Master_Pro_Carto.pyt`) را اضافه کنید تا همه‌ی افزونه‌ها کنار هم باشند.

## ۶) پارامترها به زبان ساده

### الف) ابزارهای «ساخت» (Create Bridge / Create Culvert)

| پارامتر (نام در پنجره) | معنی به زبان ساده | پیش‌فرض |
|------|------|:----:|
| Road centerlines (Polyline) | لایه(های) خط جاده. می‌توانید چند لایه انتخاب کنید. | — (الزامی) |
| Drainage / canals (Polyline) | لایه(های) خط آبراهه/کانال. چندتایی مجاز است. | — (الزامی) |
| Output location (FileGDB or Folder) | محل ذخیره‌ی خروجی (یک `.gdb` یا یک پوشه) | — (الزامی) |
| Output points feature class name | نام لایه‌ی نقطه‌ای خروجی | `P_Bridge` / `Pnt_Culvert` |
| Rotation sampling distance (map units) | فاصله‌ای که برای اندازه‌گیری جهت خط نمونه‌برداری می‌شود (بر حسب واحد نقشه). عدد کوچک‌تر = حساس‌تر به پیچ‌وخم محلی. | `8.0` |
| Rotation field name | نام فیلدی که زاویه‌ی نهایی نماد در آن نوشته می‌شود (اگر نباشد ساخته می‌شود). | `ROTATION` |
| Rotation type | نوع زاویه: `GEOGRAPHIC` (۰=شمال، ساعتگرد) یا `ARITHMETIC` (ریاضی، ۰=شرق، پادساعتگرد). | `GEOGRAPHIC` |
| Add output to map + set rotation symbology | افزودن خروجی به نقشه و تنظیم نمادگذاری چرخشی. | روشن |
| Optional layer template (.lyr) | فایل قالب نماد (اختیاری) برای ظاهر دلخواه. | — |
| Endpoint tolerance (map units) | تلورانس برای حذف تقاطع‌های الکی انتهایی/سه‌راهی. اگر نقطه‌ها سر خطوط نزدیک‌تر از این مقدار باشند، آن تقاطع نادیده گرفته می‌شود. | `2.0` |

> 🔎 **نکته درباره‌ی GEOGRAPHIC:** در این حالت یک افست **۹۰+ درجه** اعمال می‌شود تا نماد
> به‌صورت **عمود بر خط** (یعنی روی خط بنشیند) قرار بگیرد، نه موازی آن.

### ب) ابزارهای «چرخش نقاط موجود» (Rotate Existing)

| پارامتر | معنی به زبان ساده | پیش‌فرض |
|------|------|:----:|
| Existing points (Point/Multipoint) | لایه‌ی نقاط موجود که می‌خواهید زاویه‌شان به‌روز شود. | — (الزامی) |
| Road centerlines / Drainage (Polyline) | لایه‌ی مرجع (جاده برای پل، آبراهه برای آبگذر) که جهت از روی آن گرفته می‌شود. چندتایی مجاز است. | — (الزامی) |
| Update mode | `COPY_TO_OUTPUT` یک کپی جدید می‌سازد، یا `UPDATE_IN_PLACE` همان لایه را به‌روز می‌کند. | `COPY_TO_OUTPUT` |
| Output location / FC name | محل و نام خروجی (فقط وقتی COPY_TO_OUTPUT است). | — |
| Rotation sampling distance | مثل بالا. | `8.0` |
| Rotation field name | فیلد زاویه. | `ROTATION` |
| Rotation type | `GEOGRAPHIC` یا `ARITHMETIC`. | `GEOGRAPHIC` |
| Add output to map | افزودن خروجی به نقشه. | روشن |
| Template .lyr | قالب نماد اختیاری. | — |

## ۷) راهنمای گام‌به‌گام استفاده (مثال ساخت پل)

1. لایه‌های **جاده** و **آبراهه** را به نقشه اضافه کنید و مطمئن شوید سیستم مختصات دارند.
2. جعبه‌ابزار را طبق بخش ۵ بارگذاری کنید و ابزار **«01) Create Bridge Points»** را باز کنید.
3. در **Road centerlines**، لایه(های) جاده را انتخاب کنید.
4. در **Drainage / canals**، لایه(های) آبراهه را انتخاب کنید.
5. در **Output location** یک `.gdb` و در **Output name** یک نام (مثلاً `P_Bridge`) بدهید.
6. مقدار **Rotation sampling distance** را در حد چند متر بگذارید (پیش‌فرض ۸ معمولاً خوب است).
7. **Rotation type** را روی `GEOGRAPHIC` بگذارید تا نماد عمود بر خط بنشیند.
8. اگر نمی‌خواهید تقاطع‌های انتهایی الکی نماد بسازند، **Endpoint tolerance** را تنظیم کنید
   (پیش‌فرض ۲؛ خود ابزار بر اساس فاصله‌ی نمونه‌گیری مقدار پیشنهادی می‌دهد).
9. روی **Run** بزنید.
10. در پنجره‌ی پیام‌ها، مراحل و تعداد نقاط ساخته‌شده را ببینید. خروجی به نقشه اضافه می‌شود.

برای **آبگذر**، همین مراحل را با ابزار **«02) Create Culvert Points»** انجام دهید (جهت
از روی آبراهه گرفته می‌شود).

برای **به‌روزرسانی زاویه‌ی نقاط موجود**، ابزار ۰۳ یا ۰۴ را باز کنید، لایه‌ی نقاط و
لایه‌ی مرجع را بدهید، حالت به‌روزرسانی را انتخاب کنید و Run بزنید.

---

## ۸) داده‌ی ورودی موردانتظار

- **جاده‌ها:** لایه‌ی خطی (Polyline). می‌تواند چند لایه باشد.
- **آبراهه‌ها/کانال‌ها:** لایه‌ی خطی (Polyline).
- برای ابزارهای چرخش: **لایه‌ی نقطه‌ای (Point/Multipoint)** موجود + لایه‌ی خطی مرجع.
- داده بهتر است در سیستم مختصات تصویرشده با واحد متر باشد.

---

## ۹) خروجی چه شکلی است؟

- یک **لایه‌ی نقطه‌ای** در محل تقاطع‌های واقعی، شامل دو فیلد:
  - **`ROT_RAW`**: زاویه‌ی خام خط (آزیموت خط).
  - **`ROTATION`** (یا نامی که شما دادید): زاویه‌ی نهایی نماد (با احتساب افست ۹۰ درجه در حالت جغرافیایی).
- اگر گزینه‌ی افزودن به نقشه روشن باشد، لایه با نمادگذاری چرخشی روی نقشه ظاهر می‌شود.

---

## ۱۰) اشتباهات رایج و رفع آن‌ها

| مشکل | علت احتمالی | راه‌حل |
|------|------|--------|
| هیچ نقطه‌ای ساخته نشد | تقاطع واقعی بین جاده و آبراهه وجود ندارد، یا فقط تماس انتهایی دارند | بررسی کنید که خطوط واقعاً همدیگر را قطع می‌کنند؛ مقدار **Endpoint tolerance** را کم کنید. |
| نقاط زیادی سر خطوط ساخته شدند | تلورانس انتهایی خیلی کوچک است | مقدار **Endpoint tolerance** را بزرگ‌تر کنید. |
| نماد موازی خط است، نه روی آن | نوع چرخش روی `ARITHMETIC` بوده | نوع را به `GEOGRAPHIC` تغییر دهید. |
| خروجی فقط برای بخشی از داده ساخته شد | روی لایه انتخاب فعال داشتید | این افزونه به‌صورت پیش‌فرض کل داده را پردازش می‌کند؛ اگر مشکل ادامه داشت، انتخاب را پاک کنید (Clear Selection). |
| خطای نوشتن خروجی | مسیر خروجی معتبر نیست یا نام نامناسب است | یک `.gdb` معتبر و نام ساده (بدون فاصله/کاراکتر خاص) بدهید. |

## ۱۱) نکات و بهترین روش‌ها

- برای داده‌های بزرگ، ابتدا روی یک ناحیه‌ی کوچک آزمایش کنید تا مقادیر فاصله‌ی نمونه‌گیری و
  تلورانس را تنظیم کنید.
- اگر نمادگذاری دلخواه دارید، یک فایل `.lyr` آماده کنید و در **Template** بدهید.
- پیام‌های `[DIAG]` را در پنجره‌ی پیام بخوانید؛ به شما می‌گویند در هر مرحله چند نقطه باقی مانده.
- برای فقط اصلاح جهت نقاط قبلی، از ابزارهای ۰۳/۰۴ استفاده کنید تا مکان نقاط حفظ شود.

---

## ۱۲) تفاوت‌های نسخه‌ی ArcMap و Pro

- **رفتار، پارامترها و خروجی یکسان است.**
- نسخه‌ی Pro از `arcpy.mp` برای افزودن به نقشه استفاده می‌کند؛ نسخه‌ی ArcMap ابتدا
  `arcpy.mp` و در صورت نبود `arcpy.mapping` را امتحان می‌کند.
- فایل قالب نماد در ArcMap با پسوند `.lyr` است. در ArcGIS Pro مفهوم معادل `.lyrx`
  وجود دارد. *(نیازمند تأیید: نسخه‌ی Pro این افزونه نیز پارامتر قالب `.lyr` را نگه داشته
  است؛ سازگاری دقیق با `.lyrx` باید روی نصب واقعی Pro آزمایش شود.)*
