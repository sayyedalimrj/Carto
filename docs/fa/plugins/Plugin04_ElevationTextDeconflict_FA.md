# افزونه ۰۴ — جداسازی متن ارتفاع (Elevation Text Deconflict)

> راهنمای کامل و گام‌به‌گام برای کاربر تازه‌کار. اگر هنوز راهنمای کلی را نخوانده‌اید،
> ابتدا [راهنمای کلی Carto](../overview/00_Carto_Overview_FA.md) را ببینید.

---

## ۱) این افزونه چه می‌کند؟

متن‌های ارتفاع (مثل عددِ نقطه‌ارتفاع‌ها) گاهی روی عوارض دیگر یا روی هم می‌افتند و نقشه را
ناخوانا می‌کنند. این افزونه برای هر متن، **بهترین جای جابه‌جاشده** را پیدا می‌کند تا متن
با **موانع** برخورد نکند. متن در چند **حلقه‌ی فاصله (Rings)** و چند **جهت (Directions)**
آزمایش می‌شود تا اولین/بهترین موقعیت بدون برخورد انتخاب شود.

این افزونه **دو حالت کاری** دارد:

- **حالت A — لایه‌ی نقطه‌ای با فیلد متن:** ورودی یک لایه‌ی نقطه‌ای است و متن از یک فیلد خوانده می‌شود.
- **حالت B — لایه‌ی Annotation به‌همراه نقاط لنگر:** ورودی یک لایه‌ی Annotation واقعی است که
  به نقاط لنگر مرتبط می‌شود.

---

## ۲) نسخه‌ها: کدام برای ArcMap، کدام برای Pro

| سکو | فایل |
|------|------|
| **ArcMap** (پایتون ۲٫۷) | `Plugin04_ElevationTextDeconflict_ArcMap_v5_hardened.pyt` |
| **ArcGIS Pro** (پایتون ۳) | `Plugin04_ElevationTextDeconflict_Pro_v5_native.pyt` |

نسخه‌ی مرتب‌شده: `organized/Plugin04/ArcMap/` و `organized/Plugin04/Pro/`.

---

## ۳) ابزارهای داخل این افزونه

یک ابزار: **Elevation Text Deconflict (2 Modes)**.

---

## ۴) پیش‌نیازها و محیط

- ArcMap ۱۰ یا ArcGIS Pro.
- یک **جئودیتابیس فایلی** برای خروجی.
- برای حالت A: لایه‌ی **نقطه‌ای** + یک **فیلد متن**.
- برای حالت B: لایه‌ی **Annotation** (در جئودیتابیس) + لایه‌ی **نقاط لنگر**.
- حداقل یک لایه‌ی **مانع (Obstacle)** الزامی است.
- داده در سیستم مختصات تصویرشده با واحد متر توصیه می‌شود (فاصله‌ها بر حسب واحد نقشه‌اند).

---

## ۵) نحوه‌ی بارگذاری جعبه‌ابزار

### در ArcMap
**ArcToolbox** → راست‌کلیک → **Add Toolbox…** → انتخاب `Plugin04_ElevationTextDeconflict_ArcMap_v5_hardened.pyt`.

### در ArcGIS Pro
**Catalog** → راست‌کلیک روی **Toolboxes** → **Add Toolbox** → انتخاب `Plugin04_ElevationTextDeconflict_Pro_v5_native.pyt`.

## ۶) پارامترها به زبان ساده

پارامترها زیاد هستند؛ ابتدا حالت را انتخاب کنید و فقط پارامترهای همان حالت را پر کنید.

### انتخاب حالت
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Input Mode | حالت کاری: `POINT_LAYER_WITH_TEXT_FIELD` (حالت A) یا `ANNOTATION_LAYER_AND_ANCHOR_POINTS` (حالت B). | حالت A |

### پارامترهای حالت A
| پارامتر | معنی |
|------|------|
| (Mode A) Input Point Layer | لایه‌ی نقطه‌ای ورودی. |
| (Mode A) Text Field | فیلدی که متن از آن خوانده می‌شود. |

### پارامترهای حالت B
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| (Mode B) Annotation Layer | لایه‌ی Annotation در جئودیتابیس. | — |
| (Mode B) Anchor Points Layer | لایه‌ی نقاط لنگر. | — |
| (Mode B) Annotation-to-Anchor Link Method | روش اتصال: `NEAREST_POINT` (نزدیک‌ترین نقطه) یا `FEATUREID_MATCH` (تطبیق با شناسه). | `NEAREST_POINT` |
| (Mode B) FeatureID Field | فیلد شناسه برای حالت FEATUREID_MATCH. | `FeatureID` |
| (Mode B) Max Anchor Match Distance | حداکثر فاصله‌ی تطبیق لنگر (خالی = بدون محدودیت). | خالی |

### تنظیمات جست‌وجو (Search)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Rings (map units) | فهرست فاصله‌های آزمایش، مثلاً «۲ ۴ ۶» (هر چه دورتر، انتخاب بعدی). | `2 4 6` |
| Directions (angles count) | تعداد جهت‌های آزمایش دور هر نقطه: ۸، ۱۶، ۲۴ یا ۳۶. | `16` |
| Obstacle Layers | لایه(های) مانع که متن نباید رویشان بیفتد (الزامی، چندتایی). | — |
| Conflict Test Mode | دقت در برابر سرعت: `FAST_EXTENT_ONLY`, `BALANCED_EXTENT_THEN_GEOMETRY`, `ACCURATE_GEOMETRY_ONLY`. | `BALANCED…` |
| Max Features per Obstacle Layer | (منسوخ؛ در نسخه‌ی ۶ نادیده گرفته می‌شود). | `0` |
| Padding (map units) [Mode A] | حاشیه‌ی اضافی دور جعبه‌ی متن (فقط حالت A). | `0.0` |
| Extra Obstacle Search Distance | فاصله‌ی جست‌وجوی اضافی برای موانع. | `0.0` |

### مقیاس و قلم (Scale / Font)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Reference Scale | مقیاس مرجع (مثلاً ۲۵۰۰۰ برای ۱:۲۵۰۰۰). | `25000` |
| (Mode A) Font Size (pt) | اندازه‌ی قلم در حالت A. | `8.0` |
| (Mode A) Character Width Multiplier | ضریب عرض کاراکتر (۱٫۰ = بدون تنظیم). | `1.0` |

### گزارش و اشکال‌زدایی (Reporting / Debug)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Report Text Encoding Mode | حالت کدگذاری متن گزارش: `UNICODE_BEST_EFFORT` یا `ASCII_SAFE_REPLACE`. | `ASCII_SAFE_REPLACE` |
| Preview Only | فقط پیش‌نمایش؛ کپی حالت B تغییر نمی‌کند. | خاموش |
| Debug Level | سطح جزئیات لاگ: `OFF`, `BASIC`, `VERBOSE`. | `BASIC` |
| Debug Log File | مسیر فایل لاگ (اختیاری). | — |

### گزینه‌های بیشتر (Additional Options)
| پارامتر | معنی | پیش‌فرض |
|------|------|:----:|
| Create 'Moved Only' Output | خروجی جداگانه فقط برای موارد جابه‌جاشده. | روشن |
| Search Pattern | الگوی جست‌وجو: `FIXED_RINGS`, `SPIRAL`, `GREEDY`. | `FIXED_RINGS` |
| (SPIRAL) Step | گام مارپیچ (۰ = خودکار). | `0.0` |
| Direction Bias | تمایل جهت: `NONE`, `CARDINAL_FIRST`, `DIAGONAL_FIRST`. | `CARDINAL_FIRST` |
| (Mode A) Avoid Label-Label Conflicts | جلوگیری از برخورد متن با متن. | روشن |
| (Mode A) Use Rotated Conflict Box | استفاده از جعبه‌ی برخورد چرخیده. | روشن |
| (Mode B) Apply Rotation to 'Angle' Field | اعمال چرخش روی فیلد Angle. | خاموش |
| (Mode B) Rotation Write Mode | نحوه‌ی نوشتن چرخش: `SET_ABSOLUTE` یا `ADD_DELTA`. | `SET_ABSOLUTE` |
| (Mode B) Create Label-Position Points Output | ساخت لایه‌ی نقاط موقعیت برچسب. | روشن |
| Create Leader Lines Output (Polyline) | ساخت خطوط راهنما (Leader). | خاموش |
| Leader Lines: Moved Only | خطوط راهنما فقط برای موارد جابه‌جاشده. | روشن |
| (Mode B) Reverse Offset Direction | معکوس‌کردن جهت آفست. | خاموش |
| Use legacy obstacle evaluation | روش قدیمی ارزیابی موانع (کندتر؛ روش پیش‌فرض جدید سریع‌تر است). | خاموش |

## ۷) راهنمای گام‌به‌گام استفاده (حالت A)

1. لایه‌ی نقطه‌ای ارتفاع و لایه(های) مانع را به نقشه اضافه کنید.
2. ابزار را باز کنید و **Input Mode** را روی `POINT_LAYER_WITH_TEXT_FIELD` بگذارید.
3. لایه‌ی نقطه‌ای را در **Input Point Layer** و فیلد متن را در **Text Field** بگذارید.
4. در **Obstacle Layers** موانع را اضافه کنید (الزامی).
5. **Rings** را تنظیم کنید (مثلاً «۲ ۴ ۶» یعنی ابتدا ۲ واحد، بعد ۴، بعد ۶ را امتحان کن).
6. **Directions** را روی ۱۶ بگذارید (بیشتر = دقیق‌تر اما کندتر).
7. **Reference Scale** و **Font Size** را مطابق نقشه‌تان تنظیم کنید.
8. یک محل خروجی (جئودیتابیس) برای گزارش‌ها در نظر بگیرید.
9. روی **Run** بزنید و خروجی‌ها را در نقشه و گزارش بررسی کنید.

برای **حالت B**، به‌جای لایه‌ی نقطه‌ای، لایه‌ی Annotation و نقاط لنگر را بدهید و روش
اتصال (Link Method) را انتخاب کنید. اگر می‌خواهید فقط نتیجه را ببینید بدون تغییر داده،
**Preview Only** را روشن کنید.

---

## ۸) داده‌ی ورودی موردانتظار

- **حالت A:** لایه‌ی نقطه‌ای + فیلد متن.
- **حالت B:** لایه‌ی Annotation (GDB) + لایه‌ی نقاط لنگر.
- **موانع:** حداقل یک لایه (نقطه/خط/پلیگون).

---

## ۹) خروجی چه شکلی است؟

- **گزارش همه‌ی موارد** و **گزارش موارد حل‌نشده** (لایه‌ای).
- **کپی جابه‌جاشده** و (اختیاری) **کپی فقط-جابه‌جاشده‌ها**.
- (اختیاری) **نقاط موقعیت برچسب** و **خطوط راهنما (Leader)**.
- داده‌ی اصلی شما در حالت پیش‌فرض دست‌نخورده می‌ماند (به‌ویژه با Preview Only).

---

## ۱۰) اشتباهات رایج و رفع آن‌ها

| مشکل | علت احتمالی | راه‌حل |
|------|------|--------|
| ابزار اجرا نمی‌شود | لایه‌ی مانع وارد نشده (الزامی است) | حداقل یک لایه در **Obstacle Layers** بگذارید. |
| متن‌ها جابه‌جا نشدند | حلقه‌های فاصله خیلی کوچک یا تعداد جهت کم | مقادیر **Rings** را بزرگ‌تر و **Directions** را بیشتر کنید. |
| اجرا خیلی کند است | حالت تست دقیق روی داده‌ی بزرگ | **Conflict Test Mode** را روی `BALANCED…` یا `FAST_EXTENT_ONLY` بگذارید و legacy را خاموش کنید. |
| اتصال Annotation به لنگر اشتباه است (حالت B) | روش اتصال نامناسب | اگر شناسه دارید از `FEATUREID_MATCH` استفاده کنید؛ وگرنه **Max Anchor Match Distance** را تنظیم کنید. |
| متن گزارش به‌هم‌ریخته است | کدگذاری متن | حالت گزارش را روی `ASCII_SAFE_REPLACE` بگذارید. |

---

## ۱۱) نکات و بهترین روش‌ها

- ابتدا با **Preview Only** نتیجه را ببینید و سپس اجرای واقعی انجام دهید (مخصوصاً حالت B).
- مقدار **Reference Scale** باید با مقیاس واقعی چاپ بخواند تا اندازه‌ی متن درست محاسبه شود.
- برای داده‌ی بزرگ، روش پیش‌فرض (غیر-legacy) و حالت تست `BALANCED…` تعادل خوبی بین سرعت و دقت می‌دهند.
- خطوط راهنما (Leader Lines) به خواننده کمک می‌کنند بفهمد متن جابه‌جاشده به کدام نقطه تعلق دارد.

## ۱۲) تفاوت‌های نسخه‌ی ArcMap و Pro

- رفتار، پارامترها و خروجی یکسان است.
- نسخه‌ی Pro فقط از `arcpy.mp` استفاده می‌کند.
