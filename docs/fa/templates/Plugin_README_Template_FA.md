## ۵) نحوه‌ی بارگذاری جعبه‌ابزار

### در ArcMap
**ArcToolbox** → راست‌کلیک → **Add Toolbox…** → انتخاب `[[نام فایل ArcMap]].pyt`.

### در ArcGIS Pro
**Catalog** → راست‌کلیک روی **Toolboxes** → **Add Toolbox** → انتخاب `[[نام فایل Pro]].pyt`.
