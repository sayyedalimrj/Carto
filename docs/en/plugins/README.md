# Per-Plugin Documentation (English)

The complete, beginner-friendly per-plugin guides are currently written in **Persian**
under [`docs/fa/plugins/`](../../fa/plugins/). Each guide follows the same structure:
what it does, ArcMap vs Pro builds, prerequisites, loading, parameters (in plain language),
step-by-step usage, expected input, output, common mistakes, tips, ArcMap/Pro differences,
and legacy notes.

English per-plugin guides are planned. To author them, copy the structure from the Persian
template at [`docs/fa/templates/Plugin_README_Template_FA.md`](../../fa/templates/Plugin_README_Template_FA.md)
and translate, keeping headings and parameter tables consistent.
